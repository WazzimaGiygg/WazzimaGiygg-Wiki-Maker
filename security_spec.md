# Security Specification — WazzimaGiygg Maker

## 1. Data Invariants
1. **Page Slug & Identity Integrity**: Every `/pages/{slug}` document must have `slug == {slug}`, `slug` matching `^[a-zA-Z0-9_\-]+$` (1..128 chars), `authorId == request.auth.uid` on create, and `authorId` and `createdAt` remain strictly immutable on update.
2. **Temporal Integrity**: `createdAt == request.time` on create; `updatedAt == request.time` on create and update.
3. **Version Monotonicity, Collaborator Locking & User/Discussion Page Ownership**: On create, `version == 1`. On update, `version == existing().version + 1`. If `existing().isLocked == true` or `existing().visibility == 'private'` or `isUserOrDiscussionPage(slug, existing())` (personal user pages and `-discussion` pages), only the page `authorId` or a verified non-blocked admin may update or delete the page. Only the `authorId` or admin may change `isLocked` or `visibility`.
4. **Master Gate & Batch Atomicity on Subcollections**: `/pages/{slug}/revisions/{revisionId}` must use `revisionId == 'v_' + string(version)` and match `getAfter(/pages/{slug})` (`title`, `content`, `pageVisibility`, `pageAuthorId`, `version`, `editorId == lastEditorId`, `updatedAt == request.time`). `/pages/{slug}/comments/{commentId}` and `/pages/{slug}/ratings/{userId}` must verify via `get(/pages/{slug})` that the parent page exists, `pageSlug == slug`, `pageAuthorId == parent.authorId`, `pageVisibility == parent.visibility`, and respect private access; ratings must additionally enforce `{userId} == request.auth.uid` on user writes and integer `score` in `1..5`. `/collaborators/{userId}/edits/{editId}` must verify both parent collaborator and target page exist after batch commit with synced `pageTitle`, `pageVisibility`, `version`, `lastEditorId`, and `updatedAt`.
5. **PII Isolation & URI Hardening**: Email addresses live exclusively in `/users/{userId}/private/info` (`docId == 'info'`, valid email format) readable only by `request.auth.uid == userId` or verified non-blocked admin. `/collaborators/{userId}` stores only non-PII display metadata (`uid`, `displayName`, `photoURL` restricted to empty or `https?://`).
6. **Governance & Anti-Escalation**: Only verified, non-blocked admins (`!exists(/blocked_users/uid)` and `/admins/{uid}.data.role in ['admin', 'bureaucrat']`) hold governance privileges. Regular admins cannot block, unblock, or LGPD-purge admins or bureaucrats (`canModerateTarget(uid)`), no actor may modify their own `/admins/{uid}` record or target the primary bootstrapped bureaucrat (`isTargetBootstrappedBureaucrat(uid)`), and LGPD audit log entries require `canModerateTarget(targetUid)`.
7. **Evaluation Order (Denial-of-Wallet Guard)**: Every write rule validates `isVerified()`, `isValidId()`, static blueprint schema (`keys().hasAll`/`hasOnly`), and temporal/immutability invariants before issuing `exists()` or `get()` lookups.
8. **Page Header Banner Integrity**: Optional `headerImageUrl` on `/pages/{slug}` must be empty, an `http(s)://` URL (`<= 1000` chars), or a raster-only base64 data URI (`png|jpeg|jpg|webp|gif|avif`, `<= 200000` chars); SVG, HTML, and `javascript:` payloads are rejected.
9. **Profile Watchlist Isolation & Target Integrity**: `/collaborators/{userId}/watchlist/{pageSlug}` is strictly owner/admin readable (`allow list` requires `resource.data.userId == request.auth.uid || isAdmin()`), enforces `userId == request.auth.uid`, verifies both parent collaborator and target `/pages/{pageSlug}` exist, and blocks watching another author's `private` page.

## 2. Adversarial Red Team Payloads
1. **Identity Spoofing on Page Create**: Authenticated user `uid_attacker` creates `/pages/hijack` with `authorId: "uid_victim"`. -> **Expected: PERMISSION_DENIED**
2. **Shadow / Ghost Field Injection**: User creates or updates `/pages/ghost` with extra keys (`isFeatured: true` or `role: "admin"`). -> **Expected: PERMISSION_DENIED**
3. **ID Poisoning**: User creates `/pages/bad..$slug!@#` with invalid characters or length > 128. -> **Expected: PERMISSION_DENIED**
4. **Immortal Field Mutation**: Collaborator updates `/pages/start` attempting to change `authorId` or `createdAt`. -> **Expected: PERMISSION_DENIED**
5. **Locked Page Bypass**: Non-author collaborator attempts to update `/pages/locked-page` where `isLocked == true`. -> **Expected: PERMISSION_DENIED**
6. **Privilege Escalation on Lock/Visibility**: Non-author collaborator attempts to set `isLocked: true` or `visibility: "private"` on a public page created by another user. -> **Expected: PERMISSION_DENIED**
7. **Timestamp Forgery**: User submits `createdAt` or `updatedAt` with a past client timestamp instead of `request.time`. -> **Expected: PERMISSION_DENIED**
8. **Version Jump / Replay**: Collaborator updates `/pages/start` with `version: 999` or `version: 1` instead of `existing().version + 1`. -> **Expected: PERMISSION_DENIED**
9. **Orphaned or Unsynchronized Revision Write**: User attempts to create `/pages/start/revisions/fake_id` or create `/pages/start/revisions/v_1` without updating `/pages/start` in the same atomic batch. -> **Expected: PERMISSION_DENIED**
10. **PII Leak Attempt & Private Doc Injection**: Signed-in user `uid_b` attempts to `get` `/users/uid_a/private/info`, or `uid_a` writes `/users/uid_a/private/other`. -> **Expected: PERMISSION_DENIED**
11. **Query Scraping Private Pages**: Signed-in user `uid_b` executes `list` on `/pages` without `where('visibility', '==', 'public')` or `where('authorId', '==', 'uid_b')`. -> **Expected: PERMISSION_DENIED**
12. **Unverified Email, Array Slot Poisoning & Avatar XSS**: Unverified user writes a page, user sends `tags: ["ok", 12345]`, or user writes `photoURL: "javascript:alert(1)"`. -> **Expected: PERMISSION_DENIED**
13. **Blocked Admin Self-Unblock / Bureaucrat Block Escalation**: A blocked admin attempts to delete `/blocked_users/{selfUid}` or a regular admin attempts to block a bureaucrat. -> **Expected: PERMISSION_DENIED**
14. **Primary Bootstrapped Bureaucrat Moderation Attempt**: A regular admin or secondary bureaucrat attempts to create `/blocked_users/{ownerUid}` or overwrite `/admins/{ownerUid}` targeting `mafersao1100@gmail.com`. -> **Expected: PERMISSION_DENIED**
15. **Regular Admin Privilege Escalation on `/admins` or `/extensions`**: A non-bureaucrat admin attempts to promote themselves in `/admins/{selfUid}` or mutate `/extensions/site-branding`. -> **Expected: PERMISSION_DENIED**
16. **Non-Owner Edit on Another User's Personal or Discussion Page**: A regular collaborator attempts to update `/pages/user-alice-123` or `/pages/user-alice-123-discussion` owned by `uid_alice`, even when `visibility == 'public'` and `isLocked == false`. -> **Expected: PERMISSION_DENIED**
17. **Unsafe External Link Prefix Injection**: Even a bureaucrat attempts to store `externalLinkPrefix: "javascript:alert(1)"` inside `/extensions/external-link-prefix`. -> **Expected: PERMISSION_DENIED**
18. **Out-of-Bounds Rating Score or Cross-User Vote Spoofing**: Signed-in user `uid_attacker` submits `score: 99` or writes `/pages/start/ratings/uid_victim`. -> **Expected: PERMISSION_DENIED**
19. **Unsafe Header Image URI / SVG XSS Injection**: Collaborator creates or updates `/pages/start` with `headerImageUrl: "data:image/svg+xml;base64,..."` or `"javascript:alert(1)"`. -> **Expected: PERMISSION_DENIED**
20. **Cross-User Watchlist Spoofing & Private Page Bookmarking**: Signed-in user `uid_attacker` writes `/collaborators/uid_victim/watchlist/start` or bookmarks a private page owned by `uid_victim`. -> **Expected: PERMISSION_DENIED**
